# 채용사이트 필드 카탈로그 (한국어 부가 번역)

영문 문서 [`job-site-field-catalog-20260709.md`](job-site-field-catalog-20260709.md)가
주요 문서이며, 이 파일은 읽기 편의를 위한 부가 번역이다.

## 목적과 개인정보 경계

이 카탈로그는 채용 플랫폼이 제공하는 검색 필드, 결과 필드, 공개 운반 구조를
재사용 가능한 형태로 설명한다. 후보자별 검색어, 직무 우선순위, 지역·역 목록,
경력·연봉 제한, 제외어, 커넥터 대상과 같은 값은 포함하지 않는다.

실행 시에는 현재 승인된 사용자 프로필 또는 실행 직전에 읽은 시트에서 값을
주입한다. 프로필 값과 원문 공고는 저장소가 아닌 비공개 상태 저장소 또는
무시된 실행 폴더에서만 취급한다.

## 공통 필드 축

| 축 | 용도 | 공개 카탈로그에 저장하는 내용 |
|---|---|---|
| `search_keywords` | 자유 검색어 | 필드 이름과 전달 방식만 기록 |
| 역할·직무 | 직무/카테고리 선택 | 카테고리의 유형과 매핑 규칙 |
| 경력 | 신입·경력·범위 | 범위의 자료형과 검증 규칙 |
| 지역·역세권 | 근무 지역과 별도 역 검색 경로 | 지역/역 필드의 구조와 `query_path` |
| 고용·근무 형태 | 정규·비정규·원격 등 | 플랫폼이 노출하는 선택 필드 |
| 보상·학력 | 연봉과 학력 | 값의 자료형과 미제공 처리 |
| 게시·마감·상태 | 활성 여부와 최신성 | 날짜·상태 원천과 불확실성 처리 |

## 적용 규칙

1. 현재 요청에서 승인된 프로필의 검색어와 제한만 각 플랫폼 필드에 매핑한다.
2. 지역 검색과 역세권 검색을 모두 요청한 경우 `query_path`를 분리해 실행하고,
   상세 확인 후 같은 플랫폼의 ID 또는 canonical URL로 중복을 합친다.
3. 목록 결과만으로 역할·경력·지역·마감 상태를 확정하지 않는다. 상세 페이지의
   업무, 요건, 날짜, 상태를 확인하고 근거 수준을 기록한다.
4. 마감 또는 상태 불명 공고는 추천하지 않는다. 상태를 확인할 수 없으면
   `unknown`과 검증 시각을 남긴다.
5. 플랫폼 간 같은 회사·직무는 사용자가 별도로 통합을 요청하지 않는 한 각각
   보존한다.

## 재검증이 필요한 영역

- 내부 지역·직무·스킬 코드 전체 사전과 로그인 전용 필터
- 동적으로 바뀌는 기술 스택 ID와 쿼리 파라미터
- 로그인·약관·재배포 조건이 적용되는 상세 데이터
- 오래된 게시물의 현재 상태와 지원 버튼 노출 여부

실행 시 공개 응답을 다시 확인하고, 쿠키·인증 헤더·토큰·연락처·상세 페이지
전문은 저장하지 않는다.
