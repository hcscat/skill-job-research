# 개인정보 보호와 로컬 상태 설계

영문 [`security-and-local-state.md`](security-and-local-state.md)가 주요 문서이며, 이 파일은 부가 번역이다.

## 저장소와 사용자 데이터 분리

Git 저장소에는 Skill 코드, 일반화된 정책, 공개 채용사이트 메타데이터, 합성 예제와 테스트만 둔다. 이력서, 경력기술서, 연락처, 프로필, 로그인 세션, 쿠키, 실행 결과, 선호 기록은 저장소 밖에 둔다.

기본 저장 위치는 운영체제에 따라 다르며 `JOB_RESEARCH_MATCH_HOME`으로 변경할 수 있다.

- macOS: `~/Library/Application Support/job-research-match`
- Linux: `${XDG_DATA_HOME:-~/.local/share}/job-research-match`
- Windows: `%LOCALAPPDATA%\job-research-match`

## 로그인 정보

비밀번호나 쿠키를 JSON/TOML 설정에 저장하지 않는다. 사용자가 직접 로그인한 브라우저 세션이나 운영체제의 자격증명 저장소를 이용한다. Skill 설정에는 사이트별로 `browser-session`, `manual`, `public-only` 같은 비밀이 아닌 정책만 저장한다.

헤드리스 브라우저 세션 파일은 사실상 로그인 권한이므로 기본적으로 만들지 않는다. 꼭 필요한 경우 사용자 동의를 받고 Git 밖에서 소유자 전용 권한과 짧은 보존 기간을 적용해야 한다.

## 로컬 기억

Skill은 사용자의 관심·비관심 결정을 JSONL 이벤트로 저장하고, 이를 다시 계산하여 설명 가능한 선호 빈도를 만든다. 사용자는 언제든 특정 공고 기억 삭제, 전체 초기화, 현재 기억 조회를 요청할 수 있다.

## 설치·최초 사용 시 생성되는 파일

설치 또는 최초 사용 시 `local_state.py init`으로 저장소 밖의 비공개 상태를 초기화한다.

- `settings.json`: 비밀이 아닌 동작·보존 정책
- `targets.json`: 사용자가 명시적으로 허용한 스프레드시트·Drive 폴더·메일 검색 범위
- `profiles/`: 비식별 구조화 검색 프로필
- `workspace/`: 저장 전 검증하는 임시 초안
- `runs/`, `memory/`: 비식별 실행 요약과 명시적으로 허용된 피드백

저장소 안에서 실행 전용 공간이 꼭 필요한 경우에는 Git에서 무시되는 `workspace/job-collection/` 하위에만 임시 프로필·대상·실행 요약을 둔다. 이 폴더는 릴리스 매니페스트와 공개 번들에 포함하지 않으며, 원문 공고·인증 세션·연락처는 저장하지 않는다.

AI는 사용자에게 필요한 직무·기술·경력·지역·근무방식·고용형태·보상·제외조건·임계값을 물어보고, 저장 동의를 받은 경우에만 이 파일을 생성하거나 갱신한다. 실제 사용자 값은 공개 예제·테스트·참조 문서·Git 저장소에 기록하지 않는다.

## 공개 저장소 주의

파일을 현재 브랜치에서 삭제해도 기존 Git 이력의 개인정보는 사라지지 않는다. 접근 가능한 브랜치·태그를 검사하고 발견 사항에 맞는 범위의 조치를 제안한다. 일상적인 갱신에 새 저장소나 새 루트는 필요하지 않으며, 이력 재작성·ref 제거·강제 푸시는 별도로 허가받아야 한다. 민감한 보관 ref를 공개하지 않는다. 공개 호스팅 서비스가 이전 커밋 객체를 해시로 계속 제공하면 일반 push만으로는 제거를 보장할 수 없으므로 호스팅 서비스의 삭제 절차를 별도로 요청한다.

## 지침 파일과 검증 경계

AI 에이전트 지침 파일과 도구 폴더는 모든 깊이에서 로컬 전용이다(이름 목록은 `docs/specs/local-only-instruction-files/spec.md`). 공유 무시 규칙이 이를 제외하고, 프라이버시 검사는 내용과 관계없이 작업 파일·index blob·릴리스 트리에서 거부한다. 이미 추적된 파일은 무시 규칙으로 추적 해제되지 않으며, 로컬 사본을 유지한 채 추적을 해제하려면 명시적 허가가 필요하다. 이력 검사는 이 정책 이전에 공개된 루트 지침 하나만 허용한다. 릴리스와 설치 매니페스트에서도 Git 무시 규칙과 별도로 제외한다.

작업 파일·실제 index blob·접근 가능한 이력·생성된 패키지를 각각 검사한다. 패턴 검사 외에 예제 수동 검토와 실행 시에만 제공하는 개인 정보 표식을 사용한다. 바이너리나 과대 파일은 미해결 항목이지 통과가 아니다. 접근 불가 원격 객체, fork, 클라우드 버전 이력, 무관한 개인 문서는 로컬 검사 범위에 포함되지 않는다.

원본 소스·설치된 스킬·비공개 실행 상태는 서로 다른 대상이다. 소스 수정만으로 설치본까지 갱신됐다고 보고하지 않는다. 설치와 실제 계정 변경은 별도 작업이다.
