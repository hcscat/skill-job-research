# Job Research Match Skill 개발 계획

## 완료 범위

- 기존 크롤러 앱, 대시보드, 서버, MCP 개발 제거
- Codex와 Claude Code가 공유할 수 있는 `SKILL.md` 중심 구조
- 태그된 문서와 사용자 작성 프로필의 입력 우선순위
- 채용공고 정규화·매칭 정책
- 로그인과 로컬 상태 보안 정책
- 설명 가능하고 삭제 가능한 선호 기억 도구
- 필요 시 실행과 cron/에이전트 자동화 가이드
- 개인정보 사전 검사 도구

## 다음 평가 단계

1. 개인정보를 제거한 합성 프로필과 공고 세트로 기능 검증
2. 사용자가 직접 태그한 실제 문서로 프로필 추출 정확도 확인
3. 실제 활성 공고 20개로 점수·등급 검토
4. 사이트별 로그인 세션 동작을 대화형 환경에서 개별 확인
5. 사용자가 정한 일정으로 자동화 생성 및 1회 시험 실행

실제 이력서나 로그인 세션이 필요한 단계는 사용자가 파일 또는 로그인 환경을 명시한 요청에서만 수행한다.
