# Job Research Match Skill 개발 계획

영문 [`development-plan.md`](development-plan.md)가 주요 문서이며, 이 파일은 부가 번역이다.

## 완료 범위

- 기존 크롤러 앱, 대시보드, 서버, MCP 개발 제거
- Codex와 Claude Code가 공유할 수 있는 `SKILL.md` 중심 구조
- 태그된 문서와 사용자 작성 프로필의 입력 우선순위
- 채용공고 정규화·매칭 정책
- 로그인과 로컬 상태 보안 정책
- 설명 가능하고 삭제 가능한 선호 기억 도구
- 사용자 요청 시 실행하는 수집 가이드
- 개인정보 사전 검사 도구
- 릴리스 파일 허용 목록과 개인 검색값 없는 공개 필드·운반 구조 카탈로그
- 제한된 배치의 수동 상태 이관 계획, 정확한 목적지 재조회 게이트, 선택적 기업 묶음 정렬, 현재 실행의 설정·상태 도우미
- 랠릿 공개 필터·운반 구조 및 허가 확인 규칙 등록; 이는 조사 결과이며 구현되었거나 허가된 대량 수집기가 아님

이는 소스 기능이며 현재 설치본, 실제 커넥터 접근, 플랫폼 전체 수집, 외부 쓰기 성공을 입증하지 않는다.

## 다음 평가 단계

1. 개인정보를 제거한 합성 프로필과 공고 세트로 기능 검증
2. 사용자가 직접 태그한 실제 문서로 프로필 추출 정확도 확인
3. 활성 공고 표본으로 점수·등급 검토 (운영 수집량 제한이 아님)
4. 사이트별 로그인 세션 동작을 대화형 환경에서 개별 확인

실제 이력서나 로그인 세션이 필요한 단계는 사용자가 파일 또는 로그인 환경을 명시한 요청에서만 수행한다.
