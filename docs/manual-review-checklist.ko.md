# 사용자 직접 검토 체크리스트

영문 [`manual-review-checklist.md`](manual-review-checklist.md)가 주요 문서이며, 이 파일은 부가 번역이다.

## 프로필

- 목표 직무와 산업이 현재 희망과 일치하는가
- 경력 연수와 핵심·보조 기술 구분이 정확한가
- 허용 지역, 근무방식, 고용형태, 최소 연봉이 맞는가
- 제외 직무와 키워드가 과도하거나 부족하지 않은가

## 공고

- 실제 채용 중이며 마감일이 유효한가
- 필수 기술과 우대 기술이 구분됐는가
- 회사, 근무지, 계약 형태가 명확한가
- 이미지나 동적 본문 때문에 중요한 근거가 빠지지 않았는가
- 점수 이유와 감점 이유가 원문 근거와 일치하는가
- 상시채용 문구가 실제 상태·숨김·종료 신호·마감 시각·화면 마감 문구와 일치하는가? 요청 실패는 마감이 아니라 상태 불명이다.

## 수집 범위와 시트 무결성

- 이번 실행에서 실제 헤더와 검색·점수 설정을 읽었는가
- 검색 전에 허가된 수동 상태를 처리하고 빈 값·미확인 값·목적지 없는 행은 보존했는가
- 이관 후 목적지의 정확한 값을 읽고 나서 원본을 삭제했는가? 변경되거나 충돌하는 행은 무조건 재시도하지 않고 보류했는가
- 보류·차단 플랫폼까지 검색 경로·조회 총수·탐색 경계·실제 상세 시도·제외·중복·저장 건수를 보고하는가
- 플랫폼+ID 중복은 제거하되 다른 플랫폼 공고를 합치지는 않았는가
- 요청된 기업 묶음 정렬은 기존+신규 전체에 적용하고 점수·사용자 값·수식·메모·링크를 보존했는가

## 로그인과 개인정보

- 로그인 사용을 허용한 사이트인가
- 브라우저 세션 외에 비밀번호나 쿠키가 저장되지 않았는가
- 공유 결과에서 이름, 연락처, 로컬 경로가 제거됐는가
- 이력서 업로드나 자동 지원이 발생하지 않았는가
- 공개 전 작업 파일·index blob·접근 가능한 이력·실제 패키지를 따로 검사하고, AI 지침 파일과 도구 폴더가 하나도 없는가
- 소스 검증·설치 상태·실제 서비스 검증을 구분해서 보고하는가? [개인정보 보호와 로컬 상태](security-and-local-state.md)를 참고한다.
