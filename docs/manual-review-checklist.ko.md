# 사용자 직접 검토 체크리스트

## 프로필

- 목표 직무와 산업이 현재 희망과 일치하는가
- 경력 연수와 핵심·보조 기술 구분이 정확한가
- 허용 지역, 근무방식, 고용형태, 최소 연봉이 맞는가
- 제외 직무와 키워드가 과도하거나 부족하지 않은가

## 공고

- 실제 채용 중이며 마감일이 유효한가
- 필수 기술과 우대 기술이 구분됐는가
- 회사, 근무지, 계약 형태가 명확한가
- 이미지나 동적 본문 때문에 중요한 근거가 빠지지 않았는가
- 점수 이유와 감점 이유가 원문 근거와 일치하는가

## 로그인과 개인정보

- 로그인 사용을 허용한 사이트인가
- 브라우저 세션 외에 비밀번호나 쿠키가 저장되지 않았는가
- 공유 결과에서 이름, 연락처, 로컬 경로가 제거됐는가
- 이력서 업로드나 자동 지원이 발생하지 않았는가
